# 🏠 Real Estate Property Analysis

## 🌟 Project Overview
This project analyzes real estate property data using Microsoft Excel to understand property prices, listing patterns, property types, and other factors related to property values.

---

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables
- Excel Charts
- Excel Dashboard

---

## 🎯 Business Questions
- Which city has the highest number of property listings?
- Which location has the highest average property price?
- Which property type is most common?
- Which property type has the highest average price?
- Does a larger property area generally have a higher price?
- Which city has the highest average price per square foot?
- How does the number of bedrooms affect property prices?
- What percentage of properties are Active, Sold, and Pending?
- Which furnishing type is associated with higher property prices?
- Which agent handles the highest number of property listings?

## 📈 Key Insights
- Austin has the highest number of property listings, followed by Miami and Houston.
- Brooklyn has the highest average property price among all locations.
- Houses are the most common property type, with 142 listings.
- Condos have the highest average property price at approximately ₹964,507.
- Larger properties generally have higher prices, showing a positive relationship between area and price.
- New York has the highest average price per square foot at ₹1,032.33.
- Average property prices increase with the number of bedrooms.
- Pending properties have the highest share (36.86%), followed by Sold (33.33%) and Active (29.80%).
- Unfurnished properties have the highest average price among furnishing types.
- K. Brown handles the highest number of property listings, with 101 properties.
